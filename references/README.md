# Referências de domínio

Este diretório armazena materiais de apoio, referências conceituais e fontes de conhecimento para o GeoIA.

## Subpastas

- `agriculture/`: contexto agrícola, operação em campo e planejamento.
- `cad/`: desenhos, padrões, automação e conhecimento de AutoCAD.
- `domain/`: conhecimento geral do projeto e referências de domínio.

## Objetivo

Organizar as referências que sustentam a base de treinamento do GeoIA.
