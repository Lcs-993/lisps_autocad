# GeoIA — Documentação de projeto

## Visão geral

Este diretório reúne a documentação do conceito do agente GeoIA, com foco em projetos agrícolas para pilotagem automática.

O objetivo é manter uma estrutura clara para:

- entender a origem do conceito no desenvolvimento de ferramentas para AutoCAD;
- descrever o papel do agente como projetista agrícola;
- orientar a criação de prompts e fluxos de trabalho para agentes de IA;
- documentar artefatos e entregáveis do projeto.

## Conteúdo principal

- [.claude/agents/geoai.md](../../.claude/agents/geoai.md): especificação do agente e visão funcional;
- [prompts/geoia-agent.md](../../prompts/geoia-agent.md): prompt operacional do agente;
- [artifacts/geoia/README.md](../../artifacts/geoia/README.md): diretório para artefatos gerados e entregáveis.

## Fluxo do projeto

1. Coleta de dados geoespaciais, topográficos e operacionais.
2. Modelagem do talhão, limites e rotas.
3. Geração de alternativas de projeto e layout agrícola.
4. Validação técnica e operacional.
5. Entrega de documentação e desenhos para execução e automação.

## Escopo

A documentação aqui presente conecta:

- automação de desenho em AutoCAD;
- geoprocessamento e análise espacial;
- planejamento agrícola e pilotagem automática;
- execução técnica e documentação de projeto.
