# GeoIA — Base de treinamento e documentação de domínio

## Visão geral

Este diretório reúne a documentação e o contexto que servem como base de treinamento para o GeoIA. O foco não é criar um agente pronto como produto final, mas sim registrar e organizar o conhecimento técnico que será usado para treinar a IA sobre projetos agrícolas, desenho técnico e automação em campo.

A ideia é manter uma estrutura clara para:

- entender a origem do conhecimento no desenvolvimento de ferramentas para AutoCAD;
- documentar o domínio agrícola, geoespacial e operacional;
- preservar padrões, regras e exemplos que possam ser reutilizados em treinamento;
- organizar artefatos e materiais de referência para evolução do projeto.

## Fluxo do projeto como base de treinamento

1. Registro de conhecimentos adquiridos em AutoCAD e automação de desenho.
2. Organização de regras e práticas para projetos agrícolas.
3. Estruturação de contextos geoespaciais, topográficos e operacionais.
4. Geração de conteúdo técnico para aprendizado do GeoIA.
5. Uso desses materiais como referência para evolução da IA e do domínio.

## Escopo

A documentação aqui presente conecta:

- automação de desenho em AutoCAD;
- geoprocessamento e análise espacial;
- planejamento agrícola e pilotagem automática;
- execução técnica e documentação do domínio agrícola.

O valor deste repositório está no uso pedagógico e de treinamento do conhecimento, e não em manter um agente funcional isolado.
