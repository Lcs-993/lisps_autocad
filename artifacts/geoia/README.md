# Artefatos GeoIA

Este diretório é destinado a armazenar artefatos do conceito GeoIA e do projeto agrícola.

## Conteúdo sugerido

- layouts de projeto;
- diagramas de fluxo;
- especificações de operação;
- relatórios de alternativa de projeto;
- arquivos de referência para desenho e automação.

## Objetivo

Manter entregáveis e evidências técnicas organizadas, permitindo rastreabilidade e evolução do projeto.
