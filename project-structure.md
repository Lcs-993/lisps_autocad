# Estrutura do projeto GeoIA

## Visão geral

O projeto foi organizado como uma base de conhecimento para treinamento do GeoIA, em vez de um agente funcional pronto para uso.

## Diretórios principais

- `.claude/agents/`: documentação conceitual do agente.
- `artifacts/`: entregáveis e materiais de referência.
- `data/`: dados e amostras para treinamento.
- `docs/`: documentação técnica e de domínio.
- `lisps/`: rotinas AutoLISP e ferramentas CAD.
- `menu/`: arquivos de menu Ribbon e integração do AutoCAD.
- `prompts/`: prompts-base para treinamento e uso do GeoIA.
- `references/`: materiais de apoio e referência de domínio.
- `src/`: fontes e materiais técnicos do projeto.
- `training/`: notas, lições e checklists.

## Objetivo

Servir como repositório de domínio para IA aplicada à agricultura, integração com CAD e automação de projeto.
