# Ground truth e regras de validação

Este diretório reúne regras e referências para validar a coerência dos projetos agrícolas no GeoIA.

## Conteúdo esperado

- decisões de layout aceitáveis;
- limites de operação por cultura;
- regras de declividade e drenagem;
- critérios de consistência de rota e trafegabilidade.

## Objetivo

Disponibilizar uma base de validação para avaliar a qualidade das propostas geradas pela IA.
