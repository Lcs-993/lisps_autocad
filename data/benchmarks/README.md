# Benchmarks e avaliação de qualidade

Este diretório organiza materiais para avaliação comparativa de qualidade dos projetos e das decisões do GeoIA.

## Objetivos

- comparar layouts e propostas;
- verificar consistência das decisões;
- medir qualidade técnica e viabilidade de operação;
- criar critérios de avaliação para treinamento e revisão.
