# Dados de treinamento

Este diretório reúne materiais e exemplos que podem ser usados como base de treinamento para o GeoIA.

## Subpastas

- `samples/`: exemplos organizados e prontos para uso.
- `raw/`: arquivos e materiais brutos, fontes e referências iniciais.

## Objetivo

Aumentar a qualidade do aprendizado por meio de dados relevantes ao domínio agrícola e ao desenho técnico.
